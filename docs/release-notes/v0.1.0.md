First public release. Dotiphant copies your Telegram chats into one SQLite file on your own computer and lets your AI assistant search and read it over MCP. Alpha: expect rough edges, and report them in the issue tracker.

## Added

- Telegram login as you, with your own API id (QR code by default), and a guided setup in the browser (`dotiphant open`) or the terminal (`dotiphant setup`).
- Full-history sync of chats with people and groups, including forum topics and upgraded supergroups. Channels are optional. Media download per chat with `dotiphant media`.
- Local viewer on 127.0.0.1 with full-text search, light and dark themes, and "copy as Markdown".
- MCP server over stdio with six tools: `list_chats`, `search_messages`, `get_messages`, `recent_activity`, `chat_info`, `refresh`. Read-only toward Telegram: it never sends, edits, deletes or marks messages as read.
- `dotiphant connect` for Claude Desktop, Claude Code, Codex and Cursor.
- Background refresh with `dotiphant schedule install` (LaunchAgent on macOS, systemd user timer on Linux).
- `dotiphant demo` with made-up chats, no login needed. `dotiphant doctor`, `status`, `export`, `recent` and `forget`.
- One-line installer for macOS and Linux: `curl -fsSL https://dotiphant.com/install.sh | sh`. It installs the wheel attached to this release with uv. Dotiphant ships as GitHub releases, not on PyPI.

## Experimental

- Import of Telegram Desktop JSON exports and WhatsApp "Export chat" files (.zip or .txt), with `dotiphant import`. Nothing connects to WhatsApp. Tested with sample files only, not yet with many real exports. Report a file that does not import.
- Remote access for ChatGPT, claude.ai and other apps that support remote MCP servers: `dotiphant mcp --http` with OAuth, behind an HTTPS tunnel you run. Covered by automated tests; not yet verified end to end with every client. Read `docs/remote-access.md` before you turn it on.
- Windows: data paths exist in code, and `dotiphant schedule install` prints the scheduled-task command for you to run. Windows is not tested in CI and the installer script is for macOS and Linux only. Install the wheel attached to this release with `uv tool install <wheel URL>` and report what breaks.

## Known limits and unverified

- Needs Python 3.12 or newer; uv brings a suitable one. Tested in CI on Python 3.12, 3.13 and 3.14 on Ubuntu, and 3.14 on macOS.
- Used on an account with about 500,000 messages in 300 chats; search stays fast. The first sync of a large account can take a long time and may hit Telegram flood limits; it resumes on the next run.
- Message text is passed to the model as untrusted content. That lowers the risk of prompt injection from chat messages but does not rule it out.
- The archive is not encrypted beyond your disk encryption.

## Security

- Secrets (Telegram session, API hash) live in the system keychain. Without one, they are stored in 0600 files in the data folder.
- Report vulnerabilities privately; see `SECURITY.md`.
