Telegram lets an app read your chats only with an API key of its own. You make yours once, for free, on Telegram's website. It takes about a minute.

  1. Open my.telegram.org and log in with your phone number. Telegram sends the code to your Telegram app.
  2. Click API development tools and fill in the form. Any app name works, like "Dotiphant Archive". Platform: Desktop. URL and description can stay empty.
  3. Copy App api_id and App api_hash into the fields below.

{% if ov.credentials %}Keep the saved ones{% endif %}

Dotiphant logs in as you, the way Telegram Desktop does, and only reads. It never sends, edits or deletes anything.

Connecting to Telegram...

  1. Open Telegram on your phone.
  2. Go to Settings > Devices > Link Desktop Device.
  3. Point the camera at this code.

The code refreshes by itself. Afterwards Dotiphant shows up in your Telegram devices, where you can end it at any time.

{{ check }}Code scanned.

Your account has a two-step verification password. Type it here. Dotiphant uses it once to log in and does not store it.

Good to know

Dotiphant is an unofficial app that uses the Telegram API. It is not made by Telegram.

It logs in as you and only reads: it never sends, edits or deletes anything. Your key, your login and the archive stay in the Dotiphant folder on this computer.
